CHEKA WEBSITE
Open index.html in any text editor. Edit ONLY the block marked "EDIT THIS BLOCK" near the bottom:
phone, whatsapp (digits only with country code), address, opening hours, currency, products and prices.
To put it online: Netlify > Add new project > drag this folder (or the zip) in, then use Make public and rename it (for example cheka-dealers.netlify.app).
Use a NEW Netlify project; do not replace your Cheka POS project.
